# Glossary

This file contains the shared vocabulary of the project.

## Common terms

- Financial GPS — project name and overall domain
- Financial profile — user-level financial snapshot
- Debt management — debt tracking and repayment workflows
- Scenario planning — alternate financial outcomes
- Roadmap — future planning/scheduling horizon
- Auth flow — login, token, and session lifecycle

## Rule

When a term is used across multiple teams or documents, define it here once and reference this glossary from other docs.
