# Troubleshooting

This folder captures known problems, causes, and fixes discovered during development and operations.

## Format

For each issue, document:
- symptom
- root cause
- environment or conditions
- resolution
- related files or commands
- prevention or follow-up

## Example entries

- port conflict errors
- backend startup failures
- database connectivity issues
- frontend build problems
- auth flow errors
- Docker compose drift

## Rule

Do not keep each bug only in an IDE chat or terminal scrollback. If it was a real issue, write the resolution here.
